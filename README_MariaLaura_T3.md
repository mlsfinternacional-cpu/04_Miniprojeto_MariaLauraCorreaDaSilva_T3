# Instruções de execução

## Ambiente

Projeto desenvolvido em Python utilizando VS Code, Jupyter Notebook e ambiente virtual `.venv`.

As bibliotecas `pandas` e `matplotlib` são necessárias para a execução do notebook.

Em ambiente limpo, podem ser instaladas com:

```bash
pip install pandas matplotlib
## Execução

1. Abra o projeto no VS Code.
2. Selecione o ambiente virtual `.venv`.
3. Abra o notebook `eda_varejo.ipynb`.
4. Execute as células em ordem ou utilize **Run All**.

## Base de dados

A base `Base Varejo.csv` está disponível na pasta `data` do projeto.

## Resultado

A execução do notebook reproduz as etapas de importação, tratamento,
validação, estatística descritiva, agrupamentos e conclusões da análise.
